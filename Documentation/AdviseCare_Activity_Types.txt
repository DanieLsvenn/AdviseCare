ADVISECARE ACTIVITY TYPES

Values stored in ACTIVITYLOGS.activityType (string, camelCase).
- accountId is the account that did the action (for imports and admin actions, the admin).
- activityDetail is a short English sentence with the specifics (names, emails, counts, ids), e.g. "Imported 120 accounts from students_fall2026.xlsx".
- Logged: actions a user wants to see in "View own activity history" and that the admin needs for accountability.
- Not logged here: reading/viewing data (student data access goes to ACCESSLOGS, owned by Member B), and failed sign-ins.
- Format of each line: activityType - who does it - when it is written (owner member).
- Items marked (now) are written by the current Member A code; the rest are drafts for the other members to use when they build their part.

==========
1. SIGN-IN AND OWN ACCOUNT (all users)
==========

accountLinked - any user - the Google account was linked through the account-linking email (A, now)
signedIn - any user - signed in with Google or password; detail says which and the device (A, now)
signedOut - any user - logged out of the current session (A, now)
otherSessionsSignedOut - any user - logged out of all other sessions, or of one chosen session (A, now)
passwordSet - any user - set a first password (none existed before) (A, now)
passwordChanged - any user - changed an existing password in Settings (A, now)
passwordReset - any user - set a new password through the "forgot password" email (A, now)
profileUpdated - any user - changed own username or preferred language (A, now)
avatarUpdated - any user - uploaded a new avatar (A, now)
notificationPreferencesUpdated - any user - turned the email or in-app channel on/off (A, now)
dataExported - Student - downloaded the JSON export of own record (C)
